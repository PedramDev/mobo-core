# Mobo Core 10.32.10 — Existing Store Shipping Detection Fix

## مشکل رفع‌شده

در نسخه 10.32.9، Flat Rate فعالی که قبلاً توسط Mobo Core برای بسته محصولات فروشگاه ساخته شده بود، در گزینه «استفاده از روش‌های فعلی فروشگاه» به‌عنوان روش موجود شمارش نمی‌شد. در نتیجه ویزارد با وجود روش فعال، Zone را بدون روش اعلام می‌کرد.

## تغییرات

- هر روش فعال WooCommerce به‌جز `mobo_core_shipping` برای بسته غیرموبویی معتبر است.
- Flat Rate مدیریت‌شده قبلی نیز یک روش استاندارد WooCommerce است و در حالت «استفاده از روش‌های فعلی» پذیرفته می‌شود.
- انتخاب حالت روش‌های فعلی دیگر Flat Rate تشخیص‌داده‌شده را غیرفعال نمی‌کند.
- ویزارد روش‌های تشخیص‌داده‌شده را همراه Zone و Instance ID نمایش می‌دهد.
- اجرای Repair همچنان idempotent است و Duplicate ایجاد نمی‌کند.

## سناریوی اصلاح‌شده

برای Zone «ایران - ارسال موبو» با روش فعال زیر:

- `flat_rate`
- Instance ID: `31`
- عنوان: «ارسال محصولات فروشگاه»

ویزارد باید گزینه «استفاده از روش‌های فعلی فروشگاه» را فعال کند و همان روش را برای بسته غیرموبویی نگه دارد.

## نیازمندی‌ها

- Migration دیتابیس لازم نیست.
- Portal نیاز به تغییر ندارد.
- پس از بروزرسانی، یک بار ویزارد یا Repair اجرا شود.
