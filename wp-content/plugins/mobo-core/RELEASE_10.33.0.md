# Mobo Core 10.33.0 — Shipping Mapping Only

## سیاست جدید

از این نسخه Mobo Core هیچ روش ارسال، Shipping Zone، Shipping Package یا Rate به Checkout ووکامرس اضافه یا تحمیل نمی‌کند. Checkout و هزینه ارسال کاملاً تحت مالکیت WooCommerce و افزونه‌های حمل‌ونقل فروشگاه است.

## نگاشت

مدیر برای هر روش حمل‌ونقل فعال WooCommerce یک روش ارسال موبو انتخاب می‌کند. این نگاشت برای هر سفارشی که حداقل یک محصول موبو دارد، چه سفارش فقط موبو و چه سفارش ترکیبی، مشترک است.

هنگام ثبت سفارش در موبو، افزونه Shipping Method ذخیره‌شده روی سفارش WooCommerce را می‌خواند و shipping_id نگاشت‌شده را به API موبو می‌فرستد. محصولات غیرموبویی به موبو ارسال نمی‌شوند.

## مهاجرت از 10.32.x

- Custom Shipping Methodهای موبو دیگر register نمی‌شوند.
- Split Package و Wizard حمل‌ونقل اجرا نمی‌شوند.
- Flat Rateهای پشتیبان و Mirrorهایی که خود Mobo Core ساخته بود غیرفعال می‌شوند.
- روش‌های واقعی فروشگاه حذف یا تغییر داده نمی‌شوند.
- نگاشت‌های قدیمی mobo_only/mixed اگر یکسان باشند یا فقط یکی تنظیم شده باشد، خودکار به نگاشت مشترک منتقل می‌شوند. اگر با هم تعارض داشته باشند، مدیر باید نگاشت جدید را صریحاً انتخاب کند.

## دیتابیس

Migration دیتابیس لازم نیست. نگاشت‌ها در wp_options ذخیره می‌شوند.
