# Mobo Core 10.32.7 — Mixed-cart Shipping Wizard

## هدف

راه‌اندازی حمل‌ونقل دیگر بدون مشخص‌شدن مدل عملیاتی سفارش ترکیبی اجرا نمی‌شود. مدیر فروشگاه ابتدا محل آماده‌سازی سفارش و رفتار سبد ترکیبی را در یک ویزارد سه‌مرحله‌ای انتخاب می‌کند؛ سپس افزونه تنظیمات WooCommerce را به‌صورت idempotent می‌سازد یا ترمیم می‌کند.

## پروفایل‌ها

### تجمیع در فروشگاه تهران

- سبد ترکیبی برای مشتری یک Shipping Package باقی می‌ماند.
- نرخ‌های موبو در Checkout سبد ترکیبی مخفی می‌شوند.
- مشتری روش ارسال نهایی فروشگاه را انتخاب می‌کند.
- بخش موبویی سفارش با روش داخلی انتخاب‌شده در ویزارد، به‌صورت پیش‌فرض «تحویل حضوری»، ثبت می‌شود.
- روی سفارش یادداشت عملیاتی تجمیع اضافه می‌شود.

### ارسال در دو بسته مستقل

- اقلام موبو و غیرموبو در دو Shipping Package جدا قرار می‌گیرند.
- بسته موبو فقط نرخ‌های `mobo_core_shipping` را می‌بیند.
- بسته فروشگاه فقط نرخ‌های عادی فروشگاه را می‌بیند.
- خط ارسال موبو برای تعیین `shipping_id` سفارش موبو در اولویت است.

### جلوگیری از سفارش ترکیبی

- سبد ترکیبی در Cart و Checkout کلاسیک مسدود می‌شود.
- خطا در Checkout Block / Store API نیز ثبت می‌شود.
- متن خطا توسط مدیر قابل تنظیم است.

## ایمنی

- اجرای مجدد Wizard و Installer مورد تکراری ایجاد نمی‌کند.
- Zoneها و روش‌های نامرتبط WooCommerce حذف نمی‌شوند.
- قیمت محصول، سبد، پرداخت و اقلام سفارش تغییر نمی‌کند.
- Profile قبل از مرحله مرور نهایی اعمال نمی‌شود.
- روش داخلی تجمیع باید در Contract فعال Portal وجود داشته باشد.

## Migration

Migration دیتابیس لازم نیست. تنظیمات جدید در `wp_options` ذخیره می‌شوند.
