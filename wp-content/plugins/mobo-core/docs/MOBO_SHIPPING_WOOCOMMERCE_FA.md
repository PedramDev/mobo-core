# راهنمای روش‌های ارسال موبو در WooCommerce

## راه پیشنهادی: ساخت و ترمیم خودکار

از نسخه `10.32.6` نیازی به ساخت دستی Table Rate یا نگاشت تک‌تک روش‌ها نیست.

از مسیر زیر:

```text
موبو ← تنظیمات Checkout و ارسال
```

روی دکمه زیر بزنید:

```text
ساخت و ترمیم خودکار حمل‌ونقل موبو
```

Mobo Core کلاس `محصولات موبو`، Zone لازم، Instanceهای واقعی WooCommerce، قواعد `free/static/rules`، نگاشت `shipping_id` و محاسبه با `mobo_api_price` را می‌سازد یا ترمیم می‌کند.

## رفتار اجرای مجدد

- Instance تکراری ساخته نمی‌شود؛
- روش‌های مدیریت‌شده بروزرسانی می‌شوند؛
- روش‌های منبعِ حذف یا تعلیق‌شده غیرفعال می‌شوند؛
- Zoneها و روش‌های نامرتبط WooCommerce حذف نمی‌شوند؛
- تصمیم مدیر برای فعال یا غیرفعال نگه‌داشتن یک Instance موجود حفظ می‌شود.

## مبنای مبلغ

برای خطوط موبویی، مبلغ قواعد ارسال برابر است با:

```text
mobo_api_price × quantity
```

این مقدار فقط در محاسبه حمل‌ونقل استفاده می‌شود. قیمت کاتالوگ، قیمت سبد، تخفیف، مبلغ پرداخت و اقلام سفارش تغییر نمی‌کنند.

محصولات غیرموبویی در سفارش ترکیبی وارد مبلغ قواعد موبو نمی‌شوند.

## انواع روش

- `free`: هزینه صفر؛ شرط‌های مبلغی منبع نیز اعمال می‌شوند.
- `static`: هزینه ثابت منبع.
- `rules`: انتخاب Rule بر اساس مبلغ موبویی و وزن محصولات موبو.

محدوده کشور، استان و شهر نیز از قرارداد Portal بررسی می‌شود. روش‌های عنوان‌دار مخصوص تهران در نبود محدوده صریح، فقط برای مقصد تهران نمایش داده می‌شوند.

## روش‌های حساس

روش‌هایی مانند افزودن به فاکتور قبلی، نگهداری در انبار و تحویل حضوری در اولین ساخت غیرفعال می‌مانند تا مدیر فروشگاه درباره دسترسی عمومی آن‌ها تصمیم بگیرد.

## تنظیم دستی

تنظیم دستی همچنان ممکن است، اما برای روش‌های مدیریت‌شده توسط Mobo Core توصیه نمی‌شود. برای جزئیات کامل دکمه و تست‌ها فایل زیر را ببینید:

```text
docs/MOBO_AUTOMATIC_SHIPPING_FA.md
```
